# Bioinformatics Coaching

Curriculum and environment for my 1:1 bioinformatics coaching at [dracoreach.com](https://dracoreach.com).

## The program

Four weeks, two 30-minute sessions per week, taught through real projects in GitHub Codespaces.

- **Weeks 1-2**: Bash, Git, and R. The daily toolkit: navigating data, version control, and first analyses.
- **Weeks 3-4**: Python and Nextflow. Scripting analyses and running them as reproducible pipelines.

Every concept is taught in service of a project, never as an isolated lesson. Students finish with a portfolio piece and job-ready workflow skills.

## The environment

This repo runs in GitHub Codespaces with a preconfigured container, so students start coding in minutes with zero local setup.
